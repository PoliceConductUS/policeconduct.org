## Executive Summary

The codebase-level SEO foundation is strong — clean hierarchical URLs, unique per-page
titles, canonical on every page, single H1 everywhere, sensible `noindex` on form routes,
a `lastmod`-aware sitemap index, and rich entity structured data (LegalCase, Person,
GovernmentOrganization, Report, Dataset, FAQPage).

The main problem is a **deploy gap**: the best SEO/GEO work is uncommitted on the redesign
branch and not yet on production. As of the audit, live `robots.txt` was still the bare
`Allow: /` (no form-route disallows), `/llms.txt` returned **404**, and the expanded
organization/dataset schema was not deployed.

**Top 3 priorities:** (1) deploy the redesign branch; (2) fix `BreadcrumbList` schema,
missing on the deep entity/geographic pages where it matters most; (3) add
`Article`/`NewsArticle` schema and an editorial content program to capture the
informational demand competitors own.

**Overall:** strong foundation, held back by a deploy gap and a few schema/coverage holes.

## Content Gap Recommendations

See `docs/seo/content-briefs.md` for full, writer-ready briefs. Summary:

1. **State index enrichment** — the state pages (`/[state]/`) already exist; add a state-specific editorial lede + optional FAQ schema (not a new pillar). High demand (WNYC/MuckRock own it), you have the data. High · Moderate.
2. **Editorial explainers with `NewsArticle` schema** — feeds PAA and reinforces `/llms.txt` citation context. High · Moderate.
3. **Agency settlement/liability content** — unique civil-litigation angle, no competitor matches it. High · Moderate.
4. **Glossary / expanded data-and-methods** — definitional queries + AI-citation surface. Medium · Moderate.
5. **Freshness signals on news** — `Article` schema for rich results. Medium · Quick.
