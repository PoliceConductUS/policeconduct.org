# Remove verification claims

## Why

The FAQ and other public surfaces claim manual or automatic verification that does not occur. Submission email confirmation also uses wording that can imply a report was verified.

## What Changes

Remove claims of verification or fact checking from public copy, FAQ structured data and submission messages. Describe the existing email action as email confirmation. Record the prohibition in project guidance and add rendered regression coverage. Preserve routes, API fields, token checks and data semantics.

## Impact

Public pages, shared report/footer copy, submission messages and related tests. No database migration, new policy, new review process or route change.
