# Correct case summary and notification copy

## Why

The complaint section displayed a mixed legacy field that can contain only a PACER cause code or title. The sidebar also promised updates without an update schedule or notification feature.

## What Changes

- Omit the mixed legacy summary from the case header, body, and description metadata.
- Remove unsupported statements about complete public filings and automatic updates.
- Direct visitors to retained CourtListener docket links and its alert guidance.
- Preserve case records, internal timestamps, source links, and existing routing.

## Impact

This corrects presentation only. AI complaint summaries are not generated by this change; they require an actual complaint source, attribution, and explicit AI disclosure.
