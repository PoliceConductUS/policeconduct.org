# Design

Person and compact inline action/date/case metadata form the first line; the complete labeled allegation follows. Native Record details contains remaining fields and the source link. Source-only records still have a disclosure. No duplicate allegation, truncation, new heading styles, or inline CSS.

On officer pages, move the allegation outside Record details using existing definition-list styling. Move the source link inside Record details and target a new tab. A source-only record must still have a disclosure. Keep the remaining officer-page fields and layout unchanged.
