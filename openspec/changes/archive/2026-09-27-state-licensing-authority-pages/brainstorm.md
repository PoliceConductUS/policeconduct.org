# State licensing authority pages

## Approved outcome

One licensing authority per state, directly at /<state>/licensing-authority/. The user approved implementation and manual records for as many authorities as can be verified. Preserve the existing worktree. Personnel record filtering remains paused.

## Scope

Use database-backed state paths and licensing_authority.location_path_id. Show authority identity, official website, licensing totals/action summaries and directly attributed discipline records. Education currently has no authority relationship; omit rather than infer attribution from the person's license or employer. No per-license pages or multiple-authority directory. Verify manual names/websites through official sources and use intake's persisted manual pipeline and canonical identity mappings.
