# Agency discipline counts

The user approved adding an agency-specific discipline count to the existing context line beneath each name in the agency personnel roster. Counts link to the person's discipline section and are omitted when zero. The agency page shows the number of distinct linked records, rather than a sum of roster counts. Only explicit `discipline_agency_personnel → agency_personnel` links establish attribution. The separate agency record list remains pending because its visible fields and layout are unspecified.
